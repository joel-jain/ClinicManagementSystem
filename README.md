## Features

- **Modular Design:** Dedicated modules for Receptionist, Admin, Lab Technician, and Pharmacist.
- **Receptionist Workflow:** Patient registration, appointment scheduling, and record retrieval.
- **Admin Workflow:** System configuration, user management, and overall monitoring.
- **Lab Technician Workflow:** Test management, result entry, and reporting.
- **Pharmacist Workflow:** Prescription management, inventory control, and medication dispensing.
